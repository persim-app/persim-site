タブ、広告ブロック、動画保存、リーディングモード、AI ショートカット。毎日使う機能が、静かで使いやすい場所に揃っています。

無料でダウンロード 機能を見る

macOS 12 以降 · Apple Silicon と Intel に対応

ちょうどいいブラウザー

面倒な設定は不要。Persim を開いて、検索して、見て、保存するだけです。

タブを自由に

タブの作成、ドラッグ、グループ化、ミュート、ホバープレビュー。⌘⇧A で目的のタブをすぐに見つけられます。

広告を減らし、画面をすっきり

広告ブロックを内蔵。購読ルールや自分で追加したルール、許可リストも使えます。

見つけた動画を残す

ページ内の動画を検出して保存。分割された動画はひとつの MP4 にまとまり、ダウンロードは一時停止と再開に対応します。

AI にまっすぐ質問

アドレスバーに「ai + 質問」と入力すると、よく使う AI サイトへ。ChatGPT や Claude などが新しいタブに並んでいます。

長い文章を快適に

リーディングモードがメニューや広告を除いて本文だけを表示。ページの強制ダーク表示や全ページ保存も便利です。

自分らしく設定

ライト / ダーク / システムに従う、6 色のアクセントカラー、ブックマークバーの 3 モード、25 言語の UI。

ひと目でわかる使いやすさ

新しいタブにはよく行くサイト。設定にはテーマ、アクセントカラー、言語がまとまっています。

アクセントカラーを選ぶ

上部バーのカラーボタン、またはここから切り替えられます。サイト全体が変わります。

3 ステップで快適に

ダウンロードから毎日の利用まで、ほんの数分です。

01

インストール

Mac App Store からダウンロードし、Applications フォルダーへドラッグ。アカウント登録は不要です。

02

ブックマークを持ってくる

Chrome や Edge でブックマークを HTML に書き出し、Persim のブックマークマネージャーで読み込みます。

03

好みに合わせる

設定でテーマ、色、言語を変更。前回のセッションを復元する設定もあります。

よくある質問

ダウンロード、プライバシー、日常の使い方

Persim は無料ですか？
Mac App Store から無料でダウンロードでき、基本的なブラウジングは無料で使えます。一部の高度な機能はアプリ内課金で利用できます。無料版ではタブバーに小さなバッジが表示されます。
どの Mac で使えますか？
macOS 12 以降、Apple Silicon と Intel の両方に対応しています。
履歴はアップロードされますか？
いいえ。履歴、ブックマーク、セッション、ダウンロードは Mac 内に保存され、アカウントも不要です。広告ブロックの購読更新など、必要な機能だけが通信します。
Chrome のブックマークを移行するには？
Chrome でブックマークを HTML ファイルに書き出し、Persim のブックマークマネージャーで「HTML を読み込む」を選びます。
ページ内の動画を保存するには？
メディアパネルを開いて検出された動画を選択し、ダウンロードします。分割された動画はひとつの MP4 にまとめられます。
