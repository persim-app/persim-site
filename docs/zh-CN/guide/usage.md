# 使用指南

## 工作区

Reminder 2.0.0 采用三栏布局：

- **侧边栏** — 智能列表（今天、未来 7 天、收件箱、日历、已完成、活动、废纸篓），以及你自建的列表、标签与置顶项
- **任务列表** — 所选列表中的任务，支持搜索与分组
- **详情面板** — 标题、时间、重复规则、子任务、笔记与 Markdown 描述

拖动列表与详情之间的分隔线即可调整宽度。

## 创建提醒

1. 按 `Cmd+N`、使用托盘菜单，或点击 **+**
2. 输入标题 — 新建任务窗口会让光标停留在标题栏，方便你设置时间
3. 选择日期、时间与重复规则（每天、每周、每月或自定义间隔）
4. 添加子任务、标签、优先级或更长的笔记
5. 保存，或按 Enter

### 重复规则与稍后提醒

重复规则支持指定星期几，也可设置结束日期或不设结束日期。提醒触发时，你可以在通知或提醒窗口中选择稍后提醒。

## Markdown 笔记

详情面板与独立笔记采用块级编辑。输入 `# ` 生成标题、`- ` 生成列表、`1. ` 生成有序列表、`> ` 生成引用，或输入三个反引号插入代码块。内容仍以 Markdown 保存。

## 智能列表与搜索

搜索覆盖标题、笔记与标签。把列表或标签置顶，即可固定在侧边栏顶部。已完成的任务会自动移入 **已完成**。

## 键盘快捷键

| 操作 | 快捷键 |
|---|---|
| 新建提醒 | `Cmd+N` |
| 设置 | `Cmd+,` |
| 关闭窗口 | `Cmd+W` |
| 退出 | `Cmd+Q` |

"新建提醒" 与 "显示/隐藏宠物" 的全局快捷键可在 [个性化设置](./customize.md) 中配置。

## 统计与成就

**活动** 视图展示完成趋势与连续天数。11 个内置成就会在你坚持使用的时间里悄然解锁——它们是奖励，而不是又一份待办清单。

## 桌面宠物

提醒触发时，你的伙伴会从透明悬浮窗中走出来。点击它即可互动，或使用右键菜单触发特定动画。托盘菜单可显示或隐藏宠物、暂停提醒，以及打开宠物商店。

可用的伙伴与价格请参阅 [宠物与内购](./pets.md)。
