# 简介

## 关于 Reminder

**Reminder** 是一款安静、本地优先的 macOS 提醒应用——还有一位会留意你按时完成的小小桌面伙伴。设个提醒、完成它，看着宠物随你的连续打卡一起成长。

**2.0.0** 版本是一次彻底重构：基于 Rust + [GPUI](https://gpui.rs) 打造的原生应用，不含 WebView，也没有 JavaScript 运行时。启动约一秒，整个安装包约 24 MB。

## 2.0.0 有哪些新变化

- **重新打造的任务窗口** — 撰写、安排时间、勾选完成都在一处，无需跳回列表
- **三栏工作区** — 左侧智能列表、中间任务、右侧详情；中间栏可拖动到你喜欢的宽度
- **Markdown 笔记** — 任务描述与独立笔记支持块级编辑：标题、列表、待办、引用、代码与分隔线，最终仍以 Markdown 保存
- **原生提醒** — 一次性与重复规则、稍后提醒、系统通知、提示音、全局快捷键，以及常驻菜单栏图标
- **桌面宠物** — 带精灵动画的透明悬浮窗；提醒触发时它会走出来，跟随光标，并回应点击
- **宠物商店** — 通过 StoreKit 2 预览、购买与恢复手绘伙伴
- **统计与成就** — 完成趋势、连续天数与 11 个内置成就
- **25 种界面语言**、浅色与深色主题、强调色，以及登录时启动

## 为不打扰而设计

没有信息流、没有广告，也没有你不曾请求的推送。无需账户、无需登录：提醒、笔记与宠物数据都留在你的 Mac 上。已启用 App Sandbox，应用只会访问你亲自选择的文件。

## 系统要求

- **macOS**：12 Monterey 或更高版本
- **CPU**：Apple Silicon（M 系列）或 Intel（64 位）
- **存储空间**：应用约 30 MB，外加可选的宠物包
