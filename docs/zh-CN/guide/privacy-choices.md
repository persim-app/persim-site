# 隐私选择

Reminder 把所有数据都存放在本地，因此不存在可供访问、下载或删除的服务器端档案。一切都在你的 Mac 上由你自己掌控。

## 数据留在本地

- 提醒、列表、笔记、标签与子任务
- 统计数据、连续天数与成就
- 设置、快捷键与已下载的宠物包

我们不会收集、出售或共享个人信息，也不使用第三方分析或广告服务。

## 管理或删除数据

- 在应用内删除单条提醒、列表或笔记
- 如需留存副本，可在删除前从应用内导出数据
- 退出 Reminder 并删除其容器，即可清除全部数据：

```bash
rm -rf ~/Library/Containers/com.w3cub.reminder
```

开发版构建可能把数据存放在容器之外；确切路径请查看 **设置 → 通用 → 数据文件夹**。

## 可选的网络功能

- 宠物商店目录与宠物下载仅在你打开商店或购买宠物时才会使用
- 反馈仅在你明确提交应用内表单时才会发送
- Reminder 中不存在云同步与账户，因此也无需选择退出

## 应用内购买

购买与恢复均由 Apple 处理。如需查看或管理购买记录，请使用你的 Apple ID 登录 Mac App Store。若要在新 Mac 上解锁宠物，请在宠物商店中使用 **恢复购买**。
