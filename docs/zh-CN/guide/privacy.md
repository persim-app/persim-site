# 隐私政策

_最后更新：2026-11-16_

Reminder 是一款本地优先的 macOS 应用。你的提醒、笔记、设置与宠物包均存储在你的 Mac 上。我们不设账户系统，也不会收集你的任务数据。

## 我们不会收集的内容

- 无账户、无登录、无个人资料
- 无分析、广告或追踪 SDK
- 不对提醒或笔记做云同步
- 不出售或共享个人信息

## 存储在你设备上的数据

- 提醒、列表、标签、子任务、笔记与 Markdown 内容
- 统计数据、连续天数与成就进度
- 偏好设置：语言、主题、强调色、快捷键、音效
- 已下载的宠物包，以及用于验证购买凭证的收据

这些数据保存在应用的本地容器内。删除应用容器即可将其一并清除。

## 网络请求

Reminder 仅向以下目标发起请求：

- `app-sources.w3cub.com` 用于获取宠物商店目录与下载宠物包
- Apple 的 StoreKit 服务，用于处理内购与恢复购买
- 可选的反馈表单，仅在你主动提交反馈时

你输入的反馈是唯一会离开 Mac 的内容；它不与任何账户关联，也不用于追踪。

## 应用内购买

购买完全由 Apple 通过 Mac App Store 处理。我们不会接收或存储任何支付信息。本地收据仅用于验证宠物是否已解锁。

## 儿童隐私

Reminder 的分级为 4+，不会在知情情况下收集儿童的个人信息。

## 变更

本政策的更新将连同新的日期一并发布在本页面。
