# 个性化设置

Reminder 会尽可能跟随系统设置，无法跟随的部分则安静地退到一旁。按 `Cmd+,` 或从托盘菜单打开 **设置**。

## 通用

- **显示语言** — 25 种界面语言；更改会立即应用到所有已打开的窗口
- **强调色** — 多款预设，应用于按钮、选中状态与编辑器
- **登录时启动** — 登录时自动启动 Reminder
- **始终显示托盘图标** — 即使所有窗口都已关闭，也保留菜单栏图标
- **数据文件夹 / 日志文件夹** — 直接打开本地文件夹
- **重新播放引导** — 重看首次使用引导

## 外观

浅色与深色主题默认跟随你的 macOS 设置，也可以固定其中一种。悬浮宠物窗口会随应用整体一起适配。

## 提醒

- 默认提醒时间与稍后提醒时长
- 通知提示音、宠物音效与互动音效
- "新建提醒" 与 "显示/隐藏宠物" 的全局快捷键
- 从托盘菜单暂停所有提醒

## 宠物

- 预览并切换当前伙伴
- 行为：待机动作、移动、互动反馈
- 外观：大小与动画速度
- 锁屏时暂停动画
- 打开宠物商店、导入宠物包或恢复购买

## 托盘菜单

菜单栏图标会显示今天的数量、已完成数量与下一条提醒，并提供新建提醒、暂停/继续、显示或隐藏宠物、设置与退出等快捷操作。

商店相关请参阅 [宠物与内购](./pets.md)，键盘快捷键请参阅 [使用](./usage.md)。
