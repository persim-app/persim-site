# 宠物与内购

Reminder 自带一位免费伙伴。额外的手绘宠物是可选的装饰性内购项目——不购买也完全不影响任何提醒功能。

| **全部宠物礼包** | **$19.99** | 解锁商店里全部高级宠物 |

以上价格为美元参考价。StoreKit 会在购买时按你的本地货币换算。

每只宠物都有专属的精灵动画、心情与音效。推荐宠物会在商店中以徽标标注。

## 购买宠物

1. 从托盘菜单或设置中的「宠物」区打开 **宠物商店**
2. 选择一只宠物并预览它的动画
3. 点击 **购买**，并在 App Store 中确认
4. 宠物包下载后经（SHA-256）校验并本地安装 — 无需账户
5. 选择该宠物，将其设为当前伙伴

随时点按 **恢复购买**，即可解锁你在同一 Apple ID 登录的其他 Mac 上已购买的宠物。

## 导入与导出

你可以导入已拥有的 `.catpet` 宠物包，也可以导出已安装的宠物，让伙伴随你迁移。导入的宠物包会在安装前经过校验。

## 管理宠物

在 **设置 → 宠物** 中，你可以预览当前伙伴、切换宠物、调整行为与外观、开关互动音效，以及在锁屏时暂停动画。

## 常见问题

- **购买宠物会解锁某个提醒功能吗？** 不会。内购仅为装饰性内容，用于支持开发。
- **已购买的宠物可以离线使用吗？** 可以。下载完成后，宠物包就保存在你的 Mac 上。
- **宠物包存放在哪里？** 位于应用的本地数据文件夹内；参见 [隐私选择](./privacy-choices.md)。

购买遇到问题？请参阅 [故障排查](./troubleshooting.md)。
