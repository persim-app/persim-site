# 常见问题

**问：Reminder 是什么？**

答：一款安静、本地优先的 macOS 提醒应用，带有一只桌面宠物——随着你完成提醒、保持连续打卡，它会一起成长。2.0.0 版本是基于 Rust + GPUI 的原生重构。

**问：Reminder 免费吗？**

答：是的。应用与英国短毛猫伙伴均免费。其他宠物为可选内购：每只 $3.99，或以 $19.99 购买全部宠物礼包。任何提醒功能都不需要付费。

**问：需要账户吗？**

答：不需要。没有登录、没有账户，也没有云同步。你的数据留在自己的 Mac 上。

**问：可以离线使用吗？**

答：可以。提醒、笔记、统计与宠物动画均可离线使用。只有下载新购买的宠物包才需要联网。

**问：支持哪些 macOS 版本？**

答：macOS 12 Monterey 或更高版本，支持 Apple Silicon（M 系列）与 Intel Mac。

**问：应用支持哪些语言？**

答：25 种界面语言，包括英语、简体中文、繁体中文、日语、德语、西班牙语和法语。浅色与深色主题跟随系统设置。

**问：有哪些宠物可选？**

答：英国短毛猫（免费）、柯基、哈士奇、布偶猫与柴犬（每只 $3.99），以及 $19.99 的全部宠物礼包。参见 [宠物与内购](./pets.md)。

**问：如何恢复购买？**

答：使用同一 Apple ID 登录时，打开宠物商店并点按 **恢复购买**。

**问：我的数据存放在哪里？**

答：本地存放在应用的容器内。参见 [隐私选择](./privacy-choices.md)。

**问：如何反馈问题或提出功能建议？**

答：在 [项目仓库](https://github.com/petreminder/reminder) 提交 issue，或发邮件至 [reminder@w3cub.com](mailto:reminder@w3cub.com)。
