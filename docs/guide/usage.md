# Usage Guide

## The Workspace

Reminder 2.0.0 uses a three-column layout:

- **Sidebar** — smart lists (Today, Next 7 Days, Inbox, Calendar, Completed, Activity, Trash) plus your own lists, tags and pinned items
- **Task list** — the tasks in the selected list, with search and grouping
- **Detail pane** — title, time, repeat rule, subtasks, notes and Markdown description

Drag the divider between the list and detail panes to resize them.

## Creating a Reminder

1. Press `Cmd+N`, use the tray menu, or click **+**
2. Type a title — the new task window keeps the cursor in the title field while you set the time
3. Choose a date, time and repeat rule (daily, weekly, monthly or a custom interval)
4. Add subtasks, tags, a priority or a longer note
5. Save, or press Enter

### Repeat Rules & Snooze

Repeat rules support specific weekdays, an end date or no end date. When a reminder fires you can snooze it from the notification or the reminder window.

## Notes in Markdown

The detail pane and standalone notes use block-level editing. Type `# ` for a heading, `- ` for a list, `1. ` for a numbered list, `> ` for a quote, or three backticks for a code block. Content is still stored as Markdown.

## Smart Lists & Search

Search covers titles, notes and tags. Pin a list or a tag to keep it at the top of the sidebar. Completed tasks move to **Completed** automatically.

## Keyboard Shortcuts

| Action | Shortcut |
|---|---|
| New reminder | `Cmd+N` |
| Settings | `Cmd+,` |
| Close window | `Cmd+W` |
| Quit | `Cmd+Q` |

Global shortcuts for "new reminder" and "show/hide pet" can be configured in [Customize](./customize.md).

## Statistics & Achievements

The **Activity** view shows completion trends and streak days. Eleven built-in achievements unlock quietly as you keep showing up — they are rewards, not another to-do list.

## The Desktop Pet

When a reminder fires, your companion walks out in a transparent floating window. Click it for an interaction, or use the right-click menu to trigger specific animations. The tray menu can show or hide the pet, pause reminders, and open the pet store.

See [Pets & IAP](./pets.md) for the available companions and prices.
