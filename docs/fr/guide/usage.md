# Guide d'utilisation

## L'espace de travail

Reminder 2.0.0 utilise une disposition à trois colonnes :

- **Barre latérale** — listes intelligentes (Aujourd'hui, 7 prochains jours, Boîte de réception, Calendrier, Terminées, Activité, Corbeille) ainsi que vos propres listes, étiquettes et éléments épinglés
- **Liste de tâches** — les tâches de la liste sélectionnée, avec recherche et regroupement
- **Volet de détails** — titre, heure, règle de récurrence, sous-tâches, notes et description en Markdown

Faites glisser le séparateur entre la liste et le volet de détails pour les redimensionner.

## Créer un rappel

1. Appuyez sur `Cmd+N`, utilisez le menu de la barre de menus ou cliquez sur **+**
2. Saisissez un titre — la nouvelle fenêtre de tâches garde le curseur dans le champ du titre pendant que vous réglez l'heure
3. Choisissez une date, une heure et une règle de récurrence (quotidienne, hebdomadaire, mensuelle ou intervalle personnalisé)
4. Ajoutez des sous-tâches, des étiquettes, une priorité ou une note plus longue
5. Enregistrez, ou appuyez sur Entrée

### Règles de récurrence et report

Les règles de récurrence prennent en charge des jours de semaine précis, une date de fin ou aucune date de fin. Lorsqu'un rappel se déclenche, vous pouvez le reporter depuis la notification ou la fenêtre de rappel.

## Notes en Markdown

Le volet de détails et les notes autonomes utilisent une édition par blocs. Saisissez `# ` pour un titre, `- ` pour une liste, `1. ` pour une liste numérotée, `> ` pour une citation, ou trois accents graves pour un bloc de code. Le contenu reste enregistré en Markdown.

## Listes intelligentes et recherche

La recherche porte sur les titres, les notes et les étiquettes. Épinglez une liste ou une étiquette pour la garder en haut de la barre latérale. Les tâches terminées passent automatiquement dans **Terminées**.

## Raccourcis clavier

| Action | Raccourci |
|---|---|
| Nouveau rappel | `Cmd+N` |
| Réglages | `Cmd+,` |
| Fermer la fenêtre | `Cmd+W` |
| Quitter | `Cmd+Q` |

Les raccourcis globaux pour « nouveau rappel » et « afficher/masquer le compagnon » se configurent dans [Personnalisation](./customize.md).

## Statistiques et succès

La vue **Activité** affiche les tendances de réalisation et les jours de série. Onze succès intégrés se débloquent discrètement à mesure que vous êtes régulier — ce sont des récompenses, pas une autre liste de tâches.

## Le compagnon de bureau

Lorsqu'un rappel se déclenche, votre compagnon sort dans une fenêtre flottante transparente. Cliquez dessus pour une interaction, ou utilisez le menu du clic droit pour déclencher des animations précises. Le menu de la barre de menus permet d'afficher ou de masquer le compagnon, de suspendre les rappels et d'ouvrir la boutique de compagnons.

Consultez [Compagnons et achats intégrés](./pets.md) pour les compagnons disponibles et les tarifs.
