# Guide

Bienvenue dans le guide utilisateur de Reminder. Reminder 2.0.0 est une application de rappels sereine et centrée sur le local pour macOS, entièrement reconstruite en Rust + GPUI — et elle s'accompagne d'un petit compagnon qui grandit avec votre série.
