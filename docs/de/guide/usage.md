# Verwendung

## Der Arbeitsbereich

Reminder 2.0.0 verwendet ein Layout mit drei Spalten:

- **Seitenleiste** – intelligente Listen (Heute, Nächste 7 Tage, Eingang, Kalender, Abgeschlossen, Aktivität, Papierkorb) sowie eigene Listen, Tags und angeheftete Einträge
- **Aufgabenliste** – die Aufgaben der ausgewählten Liste, mit Suche und Gruppierung
- **Detailbereich** – Titel, Uhrzeit, Wiederholungsregel, Teilaufgaben, Notizen und Markdown-Beschreibung

Ziehen Sie den Trenner zwischen Aufgabenliste und Detailbereich, um ihre Breite anzupassen.

## Erinnerung erstellen

1. Drücken Sie `Cmd+N`, nutzen Sie das Menüleisten-Menü oder klicken Sie auf **+**
2. Geben Sie einen Titel ein – das neue Aufgabenfenster hält den Cursor im Titelfeld, während Sie die Uhrzeit festlegen
3. Wählen Sie Datum, Uhrzeit und Wiederholungsregel (täglich, wöchentlich, monatlich oder ein benutzerdefiniertes Intervall)
4. Fügen Sie Teilaufgaben, Tags, eine Priorität oder eine längere Notiz hinzu
5. Speichern Sie oder drücken Sie Enter

### Wiederholungsregeln & Schlummerfunktion

Wiederholungsregeln unterstützen bestimmte Wochentage, ein Enddatum oder kein Enddatum. Wenn eine Erinnerung ausgelöst wird, können Sie sie über die Mitteilung oder das Erinnerungsfenster schlummern lassen.

## Notizen in Markdown

Der Detailbereich und eigenständige Notizen nutzen blockbasierte Bearbeitung. Geben Sie `# ` für eine Überschrift, `- ` für eine Liste, `1. ` für eine nummerierte Liste, `> ` für ein Zitat oder drei Backticks für einen Codeblock ein. Die Inhalte werden weiterhin als Markdown gespeichert.

## Intelligente Listen & Suche

Die Suche umfasst Titel, Notizen und Tags. Heften Sie eine Liste oder ein Tag an, damit sie oben in der Seitenleiste bleibt. Abgeschlossene Aufgaben wandern automatisch nach **Abgeschlossen**.

## Tastenkürzel

| Aktion | Tastenkürzel |
|---|---|
| Neue Erinnerung | `Cmd+N` |
| Einstellungen | `Cmd+,` |
| Fenster schließen | `Cmd+W` |
| Beenden | `Cmd+Q` |

Globale Tastenkürzel für das Anlegen einer Erinnerung und zum Ein- oder Ausblenden des Haustiers lassen sich unter [Anpassen](./customize.md) konfigurieren.

## Statistik & Erfolge

Die Ansicht **Aktivität** zeigt Abschlussverläufe und Serientage. 11 integrierte Erfolge schalten sich leise frei, während Sie dranbleiben – sie sind Belohnungen, keine weitere Aufgabenliste.

## Das Desktop-Haustier

Wird eine Erinnerung ausgelöst, erscheint Ihr Begleiter in einem transparenten, schwebenden Fenster. Klicken Sie darauf für eine Interaktion, oder nutzen Sie das Kontextmenü, um bestimmte Animationen auszulösen. Über das Menüleisten-Menü können Sie das Haustier ein- oder ausblenden, Erinnerungen pausieren und den Haustier-Shop öffnen.

Die verfügbaren Begleiter und Preise finden Sie unter [Haustiere & In-App-Käufe](./pets.md).
