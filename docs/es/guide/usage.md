# Guía de uso

## El espacio de trabajo

Reminder 2.0.0 usa un diseño de tres columnas:

- **Barra lateral** — listas inteligentes (Hoy, Próximos 7 días, Bandeja de entrada, Calendario, Completadas, Actividad, Papelera), además de sus propias listas, etiquetas y elementos fijados
- **Lista de tareas** — las tareas de la lista seleccionada, con búsqueda y agrupación
- **Panel de detalles** — título, hora, regla de repetición, subtareas, notas y descripción en Markdown

Arrastre el separador entre la lista y el panel de detalles para cambiar su tamaño.

## Crear un recordatorio

1. Pulse `Cmd+N`, use el menú de la barra o haga clic en **+**
2. Escriba un título — la nueva ventana de tareas mantiene el cursor en el campo de título mientras usted ajusta la hora
3. Elija una fecha, una hora y una regla de repetición (diaria, semanal, mensual o un intervalo personalizado)
4. Añada subtareas, etiquetas, una prioridad o una nota más larga
5. Guarde o pulse Intro

### Reglas de repetición y posposición

Las reglas de repetición admiten días concretos de la semana, una fecha de fin o ninguna fecha de fin. Cuando salta un recordatorio, puede posponerlo desde la notificación o desde la ventana del recordatorio.

## Notas en Markdown

El panel de detalles y las notas independientes usan edición por bloques. Escriba `# ` para un encabezado, `- ` para una lista, `1. ` para una lista numerada, `> ` para una cita o tres comillas invertidas para un bloque de código. El contenido se sigue guardando como Markdown.

## Listas inteligentes y búsqueda

La búsqueda cubre títulos, notas y etiquetas. Fije una lista o una etiqueta para mantenerla en la parte superior de la barra lateral. Las tareas completadas pasan automáticamente a **Completadas**.

## Atajos de teclado

| Acción | Atajo |
|---|---|
| Nuevo recordatorio | `Cmd+N` |
| Ajustes | `Cmd+,` |
| Cerrar ventana | `Cmd+W` |
| Salir | `Cmd+Q` |

Los atajos globales para «nuevo recordatorio» y «mostrar/ocultar mascota» se configuran en [Personalización](./customize.md).

## Estadísticas y logros

La vista **Actividad** muestra las tendencias de finalización y los días de racha. 11 logros integrados se desbloquean discretamente a medida que usted cumple: son recompensas, no otra lista de tareas.

## La mascota de escritorio

Cuando salta un recordatorio, su compañero sale a escena en una ventana flotante transparente. Haga clic en él para interactuar o use el menú contextual para activar animaciones concretas. El menú de la barra permite mostrar u ocultar la mascota, pausar los recordatorios y abrir la tienda de mascotas.

Consulte [Mascotas y compras integradas](./pets.md) para ver los compañeros disponibles y sus precios.
