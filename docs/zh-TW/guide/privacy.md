# 隱私權政策

_最後更新：2026-11-16_

Reminder 是一款本機優先的 macOS 應用程式。您的提醒事項、筆記、設定與寵物包皆存放於您的 Mac 上。我們不經營帳號系統，亦不收集您的任務資料。

## 我們不收集的資料

- 帳號、登入資訊或個人檔案
- 分析、廣告或追蹤 SDK
- 提醒事項或筆記的雲端同步
- 個人資訊的出售或分享

## 存放於裝置上的資料

- 提醒事項、清單、標籤、子任務、筆記與 Markdown 內容
- 統計資料、連續紀錄與成就進度
- 偏好設定：語言、主題、強調色、快速鍵、音效
- 已下載的寵物包，以及用於驗證所有權的購買憑證

這些資料存放於 App 的本機容器內。刪除 App 容器即會一併移除。

## 網路請求

Reminder 只會對下列對象發出請求：

- `app-sources.w3cub.com`，用於寵物商店目錄與寵物包下載
- Apple 的 StoreKit 服務，用於 App 內購買與回復
- 選用的意見回饋表單，且僅在您選擇送出意見時

您所輸入的意見回饋，是唯一可能離開 Mac 的內容；它不會與任何帳號連結，亦不會用於追蹤。

## App 內購買項目

購買流程完全由 Apple 透過 Mac App Store 處理。我們不會接收或保存付款資訊。本機購買憑證僅用於驗證寵物是否已解鎖。

## 兒童隱私

Reminder 分級為 4+，且不會刻意收集兒童的個人資訊。

## 變更

本政策的任何更新都會連同新日期公告於本頁。
