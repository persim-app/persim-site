# 介紹

## 關於 Reminder

**Reminder** 是一款沉靜、本機優先的 macOS 提醒事項 App —— 附有一位在你確實完成時會默默留意的小小桌面夥伴。設定提醒、完成它，看著你的寵物隨連續紀錄一起成長。

**2.0.0** 版是一次全面重構：以原生 Rust + [GPUI](https://gpui.rs) 打造，沒有 WebView，也沒有 JavaScript 執行環境。約一秒即可啟動，整個安裝包大約只有 24 MB。

## 2.0.0 有哪些新內容

- **重新打造的任務視窗** —— 在同一個地方寫下、排定時間並勾選完成，不必再跳回清單
- **三欄工作區** —— 左側是智慧清單、中間是任務、右側是詳細資訊；中間欄可拖曳成你喜歡的寬度
- **Markdown 筆記** —— 任務描述與獨立筆記皆支援區塊式編輯：標題、清單、待辦、引言、程式碼與分隔線，最終仍以 Markdown 儲存
- **原生提醒事項** —— 單次與週期性規則、稍後提醒、系統通知、提示音、全域快速鍵，以及常駐的選單列圖示
- **桌面寵物** —— 一個透明的浮動視窗，帶有精靈動畫；提醒觸發時牠會走出來、跟著你的游標，並回應點擊
- **寵物商店** —— 透過 StoreKit 2 預覽、購買與回復手繪夥伴
- **統計與成就** —— 完成趨勢、連續天數與 11 個內建成就
- **25 種介面語言**、淺色與深色主題、強調色，以及登入時啟動

## 刻意不干擾的設計

沒有動態牆、沒有廣告、沒有你沒要求過的通知。不需要帳號，也不用登入：你的提醒事項、筆記與寵物資料都留在你的 Mac 上。App Sandbox 已啟用，App 只會讀取你自己選取的檔案。

## 系統需求

- **macOS**：12 Monterey 以上版本
- **CPU**：Apple Silicon（M 系列）或 Intel（64 位元）
- **儲存空間**：App 約需 30 MB，外加選購的寵物包
