# 寵物與 App 內購買項目

Reminder 隨附一隻免費夥伴。其他手繪寵物為選購、純外觀的 App 內購買項目 —— 少了牠們，所有提醒功能照樣完整可用。

每隻寵物都有專屬的精靈動畫、心情與音效。推薦寵物在商店中會以標章標示。

## 購買寵物

1. 從選單列選單或「設定」中的「寵物」區塊開啟**寵物商店**
2. 選一隻寵物並預覽牠的動畫
3. 點擊**購買**，並透過 App Store 完成確認
4. 寵物包下載後會經過驗證（SHA-256）並安裝於本機 —— 不需要帳號
5. 選取該寵物，將它設為目前的夥伴

隨時點擊**回復購買項目**，即可解鎖你在另一台以相同 Apple ID 登入的 Mac 上已購買的寵物。

## 匯入與匯出

你可以匯入已擁有的 `.catpet` 寵物包，也能匯出已安裝的寵物，讓夥伴跟著你一起搬家。匯入的寵物包在安裝前都會先經過檢查。

## 管理寵物

在**設定 → 寵物**中，你可以預覽目前的夥伴、切換寵物、調整行為與外觀、開關互動音效，以及在螢幕鎖定時暫停動畫。

## 常見問題

- **購買寵物會解鎖任何提醒功能嗎？** 不會。購買項目純屬外觀，用途是支持開發。
- **購買的寵物可以離線使用嗎？** 可以。下載完成後，寵物包就存放在你的 Mac 上。
- **寵物包存放在哪裡？** 放在 App 的本機資料資料夾中；請參閱[隱私權選擇](./privacy-choices.md)。

購買時需要協助嗎？請參閱[疑難排解](./troubleshooting.md)。
