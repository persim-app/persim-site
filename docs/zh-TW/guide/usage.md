# 使用方式

## 工作區

Reminder 2.0.0 採用三欄式版面：

- **側邊欄** —— 智慧清單（今天、未來 7 天、收件匣、行事曆、已完成、活動、垃圾桶），加上你自訂的清單、標籤與釘選項目
- **任務清單** —— 所選清單中的任務，可搜尋與分組
- **詳細資訊面板** —— 標題、時間、重複規則、子任務、筆記與 Markdown 描述

拖曳清單與詳細資訊面板之間的分隔線即可調整寬度。

## 建立提醒事項

1. 按下 `Cmd+N`、使用選單列選單，或點擊 **+**
2. 輸入標題 —— 新的任務視窗會讓游標停留在標題欄，方便你接著設定時間
3. 選擇日期、時間與重複規則（每日、每週、每月或自訂間隔）
4. 加入子任務、標籤、優先順序或較長的筆記
5. 儲存，或按下 Enter

### 重複規則與稍後提醒

重複規則可指定特定星期幾、結束日期，或設為不設結束日期。提醒觸發時，你可以從通知或提醒視窗中選擇稍後提醒。

## 用 Markdown 寫筆記

詳細資訊面板與獨立筆記皆採用區塊式編輯。輸入 `# ` 建立標題、`- ` 建立清單、`1. ` 建立編號清單、`> ` 建立引言，或輸入三個反引號建立程式碼區塊。內容最終仍以 Markdown 儲存。

## 智慧清單與搜尋

搜尋涵蓋標題、筆記與標籤。釘選清單或標籤，即可讓它保持在側邊欄頂端。已完成的任務會自動移至**已完成**。

## 鍵盤快速鍵

| 動作 | 快速鍵 |
|---|---|
| 新增提醒事項 | `Cmd+N` |
| 設定 | `Cmd+,` |
| 關閉視窗 | `Cmd+W` |
| 結束 | `Cmd+Q` |

「新增提醒事項」與「顯示／隱藏寵物」的全域快速鍵可在[個人化設定](./customize.md)中調整。

## 統計與成就

**活動**檢視會顯示完成趨勢與連續天數。11 個內建成就會在你持續出現的過程中悄悄解鎖 —— 它們是獎勵，不是另一份待辦清單。

## 桌面寵物

提醒觸發時，你的夥伴會在透明的浮動視窗中走出來。點擊牠可進行互動，或使用右鍵選單觸發特定動畫。選單列選單可顯示或隱藏寵物、暫停提醒，以及開啟寵物商店。

可用的夥伴與價格請參閱[寵物與 App 內購買項目](./pets.md)。
