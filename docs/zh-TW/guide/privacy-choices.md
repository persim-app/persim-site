# 隱私權選擇

Reminder 將所有資料存放在本機，因此沒有可供存取、下載或刪除的伺服器端個人檔案。控制權始終直接掌握在您的 Mac 上。

## 您的資料留在本機

- 提醒事項、清單、筆記、標籤與子任務
- 統計資料、連續紀錄與成就
- 設定、快速鍵與已下載的寵物包

我們不會收集、出售或分享個人資訊，亦不使用第三方分析或廣告服務。

## 管理或移除資料

- 在 App 內刪除個別的提醒事項、清單或筆記
- 若需要留存副本，請先從 App 匯出資料再移除
- 結束 Reminder 並刪除其容器，即可移除全部資料：

```bash
rm -rf ~/Library/Containers/com.w3cub.reminder
```

開發版本可能會將資料存放在容器之外；請至**設定 → 一般 → 資料資料夾**查看確切路徑。

## 選用的網路功能

- 寵物商店目錄與寵物下載，僅在您開啟商店或購買寵物時才會使用
- 意見回饋僅在您明確送出 App 內表單時才會傳送
- Reminder 不存在雲端同步與帳號，因此沒有需要選擇退出的項目

## App 內購買項目

購買與回復皆由 Apple 處理。若要檢視或管理購買記錄，請使用 Mac App Store 並登入您的 Apple ID。若要在新 Mac 上解鎖寵物，請在寵物商店使用**回復購買項目**。

有疑問嗎？請寄信到 [reminder@w3cub.com](mailto:reminder@w3cub.com)，或閱讀[隱私權政策](./privacy.md)。
