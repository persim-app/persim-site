# 常見問題

**問：Reminder 是什麼？**

答：一款沉靜、本機優先的 macOS 提醒事項 App，附有桌面寵物；隨著你完成提醒、維持連續紀錄，牠會跟著成長。2.0.0 版是以 Rust + GPUI 打造的原生重構版本。

**問：Reminder 是免費的嗎？**

答：是的。App 與 British Shorthair 夥伴都免費。其他寵物為選購的 App 內購買項目：每隻 $3.99，或透過 All Pets Pack 以 $19.99 一次擁有。沒有任何提醒功能需要付費。

**問：我需要帳號嗎？**

答：不需要。不用登入、沒有帳號，也沒有雲端同步。你的資料都留在你的 Mac 上。

**問：可以離線使用嗎？**

答：可以。提醒事項、筆記、統計與寵物動畫都能離線運作。只有下載新購買的寵物包時才需要網路。

**問：支援哪些 macOS 版本？**

答：macOS 12 Monterey 以上版本，並相容 Apple Silicon（M 系列）與 Intel Mac。

**問：App 支援哪些語言？**

答：25 種介面語言，包含英文、簡體中文、繁體中文、日文、德文、西班牙文與法文。淺色與深色主題會跟隨你的系統設定。

**問：有哪些寵物可以選？**

答：British Shorthair（免費）、Corgi、Husky、Ragdoll Cat 與 Shiba Inu（每隻 $3.99），以及 $19.99 的 All Pets Pack。請參閱[寵物與 App 內購買項目](./pets.md)。

**問：如何回復購買項目？**

答：使用相同的 Apple ID 登入後，開啟寵物商店並點擊**回復購買項目**。

**問：我的資料存放在哪裡？**

答：本機，放在 App 的容器內。請參閱[隱私權選擇](./privacy-choices.md)。

**問：如何回報問題或提出功能建議？**

答：到 [專案儲存庫](https://github.com/petreminder/reminder) 開啟 issue，或寄信到 [reminder@w3cub.com](mailto:reminder@w3cub.com)。
