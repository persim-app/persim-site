# よくある質問

**Q: Reminder とは何ですか？**

A: リマインダーを完了させて連続記録を続けると育つデスクトップペットを備えた、macOS のための静かでローカルファーストなリマインダーアプリです。バージョン 2.0.0 は Rust + GPUI によるネイティブな作り直しです。

**Q: Reminder は無料ですか？**

A: はい。アプリ本体と British Shorthair の仲間は無料です。追加のペットは任意のアプリ内課金で、各 $3.99、または All Pets Pack が $19.99 です。リマインダーの機能が購入を必要とすることはありません。

**Q: アカウントは必要ですか？**

A: いいえ。ログインも、アカウントも、クラウド同期もありません。データは Mac の中に留まります。

**Q: オフラインでも使えますか？**

A: はい。リマインダー、ノート、統計、ペットのアニメーションはすべてオフラインで動作します。インターネットが必要なのは、新しく購入したペットパックをダウンロードするときだけです。

**Q: 対応している macOS のバージョンは？**

A: macOS 12 Monterey 以降で、Apple Silicon（M シリーズ）と Intel Mac に対応します。

**Q: アプリはどの言語に対応していますか？**

A: 英語、簡体字中国語、繁体字中国語、日本語、ドイツ語、スペイン語、フランス語など、25 の表示言語に対応します。ライト／ダークテーマはシステム設定に従います。

**Q: どのペットが利用できますか？**

A: British Shorthair（無料）、Corgi、Husky、Ragdoll Cat、Shiba Inu（各 $3.99）、および $19.99 の All Pets Pack です。[ペットとアプリ内課金](./pets.md) をご覧ください。

**Q: 購入を復元するには？**

A: 同じ Apple ID でサインインした状態で、ペットストアを開き **購入を復元** をタップします。

**Q: データはどこに保存されますか？**

A: アプリのコンテナ内にローカル保存されます。[プライバシーに関する選択](./privacy-choices.md) をご覧ください。

**Q: 不具合の報告や機能のリクエストはどうすればよいですか？**

A: [プロジェクトのリポジトリ](https://github.com/petreminder/reminder) で Issue を作成するか、[reminder@w3cub.com](mailto:reminder@w3cub.com) までメールでお寄せください。
