# 使い方ガイド

## ワークスペース

Reminder 2.0.0 は 3 カラム構成です:

- **サイドバー** — スマートリスト（今日、今後 7 日間、受信箱、カレンダー、完了、アクティビティ、ゴミ箱）に加え、自分で作成したリスト、タグ、ピン留めした項目
- **タスクリスト** — 選択中のリストのタスク。検索とグループ化に対応
- **詳細ペイン** — タイトル、時刻、繰り返しルール、サブタスク、ノート、Markdown の説明

リストと詳細ペインの間の境界線をドラッグすると、幅を調整できます。

## リマインダーを作成する

1. `Cmd+N` を押す、トレイメニューを使う、または **+** をクリックします
2. タイトルを入力します — 新しいタスクウィンドウでは、時刻を設定している間もカーソルがタイトル欄に留まります
3. 日付、時刻、繰り返しルール（毎日、毎週、毎月、またはカスタム間隔）を選びます
4. サブタスク、タグ、優先度、長めのノートを追加します
5. 保存するか、Enter を押します

### 繰り返しルールとスヌーズ

繰り返しルールでは、特定の曜日、終了日、または終了日なしを指定できます。リマインダーが発動したら、通知またはリマインダーウィンドウからスヌーズできます。

## Markdown で書くノート

詳細ペインと独立したノートはブロック単位で編集できます。見出しは `# `、リストは `- `、番号付きリストは `1. `、引用は `> `、コードブロックはバッククォート 3 つで入力します。内容はこれまでどおり Markdown として保存されます。

## スマートリストと検索

検索はタイトル、ノート、タグを対象にします。リストやタグをピン留めするとサイドバーの先頭に固定できます。完了したタスクは自動的に **完了** へ移動します。

## キーボードショートカット

| 操作 | ショートカット |
|---|---|
| 新しいリマインダー | `Cmd+N` |
| 設定 | `Cmd+,` |
| ウィンドウを閉じる | `Cmd+W` |
| 終了 | `Cmd+Q` |

「新しいリマインダー」と「ペットの表示／非表示」のグローバルショートカットは [カスタマイズ](./customize.md) で設定できます。

## 統計と実績

**アクティビティ** ビューには、完了の推移と連続達成日数が表示されます。11 種類の組み込み実績が、続けていくうちに静かに解除されます — これらはご褒美であり、新たなやることリストではありません。

## デスクトップペット

リマインダーが発動すると、仲間が透明なフローティングウィンドウに歩いて出てきます。クリックすると反応し、右クリックメニューから特定のアニメーションを再生できます。トレイメニューからは、ペットの表示／非表示、リマインダーの一時停止、ペットストアを開く操作が行えます。

利用できる仲間と価格については [ペットとアプリ内課金](./pets.md) をご覧ください。
