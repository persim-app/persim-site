# はじめに

## Reminder について

**Reminder** は、macOS のための静かでローカルファーストなリマインダーアプリです。やり遂げたことをそっと見届ける、小さなデスクトップの仲間が付いています。リマインダーを設定し、完了させ、連続記録とともにペットが育つのを見守りましょう。

バージョン **2.0.0** は完全な作り直しです。WebView も JavaScript ランタイムも使わない、Rust + [GPUI](https://gpui.rs) によるネイティブアプリになりました。起動はおよそ 1 秒、バンドル全体は約 24 MB です。

## 2.0.0 の内容

- **生まれ変わったタスクウィンドウ** — 作成、スケジュール、完了までを一箇所で。リストに戻る必要はありません
- **3 カラムのワークスペース** — 左にスマートリスト、中央にタスク、右に詳細。中央のカラムはお好みの幅にドラッグして調整できます
- **Markdown ノート** — タスクの説明や独立したノートをブロック単位で編集。見出し、リスト、ToDo、引用、コード、区切り線に対応し、保存形式はこれまでどおり Markdown です
- **ネイティブなリマインダー** — 単発・繰り返しルール、スヌーズ、システム通知、サウンド、グローバルショートカット、常駐のメニューバートレイ
- **デスクトップペット** — スプライトアニメーションを備えた透明なフローティングウィンドウ。リマインダーが発動すると歩き出し、カーソルを追い、クリックに反応します
- **ペットストア** — StoreKit 2 を通じてイラスト付きの仲間をプレビュー、購入、復元できます
- **統計と実績** — 完了の推移、連続達成日数、11 種類の組み込み実績
- **25 の表示言語**、ライト／ダークテーマ、アクセントカラー、ログイン時の自動起動

## 邪魔をしない設計

フィードも、広告も、求めていない通知もありません。アカウントもログインも不要で、リマインダー、ノート、ペットのデータは Mac の中に留まります。App Sandbox が有効で、アプリが触れるのはご自身で選んだファイルだけです。

## システム要件

- **macOS**: 12 Monterey 以降
- **CPU**: Apple Silicon（M シリーズ）または Intel（64 ビット）
- **ストレージ**: アプリ本体に約 30 MB、さらに任意のペットパック分
