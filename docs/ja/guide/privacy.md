# プライバシーポリシー

_最終更新日: 2026-11-16_

Reminder はローカルファーストの macOS アプリケーションです。リマインダー、ノート、設定、ペットパックはお使いの Mac に保存されます。当方はアカウントシステムを運用しておらず、タスクデータを収集することはありません。

## 収集しない情報

- アカウント、ログイン情報、プロフィール
- 解析、広告、トラッキング用の SDK
- リマインダーやノートのクラウド同期
- 個人情報の販売または共有

## デバイスに保存されるデータ

- リマインダー、リスト、タグ、サブタスク、ノート、Markdown の内容
- 統計、連続記録、実績の進捗
- 設定: 言語、テーマ、アクセントカラー、ショートカット、サウンド
- ダウンロードしたペットパック、および所有確認に用いる購入レシート

これらのデータはアプリのローカルコンテナ内にあります。アプリのコンテナを削除すると、これらも削除されます。

## ネットワーク通信

Reminder が通信を行う相手は次に限られます:

- ペットストアのカタログとペットパックのダウンロードのための `app-sources.w3cub.com`
- アプリ内課金と復元のための Apple の StoreKit サービス
- フィードバックの送信をご自身が選んだ場合に限る、任意のフィードバックフォーム

入力されたフィードバックは、Mac の外に送信されうる唯一の内容です。アカウントとは紐付けられず、トラッキングには利用されません。

## アプリ内課金

購入は Mac App Store を通じて Apple が全面的に処理します。当方が支払い情報を受け取ったり保存したりすることはありません。ローカルのレシートは、ペットが解放済みであることを確認するためだけに用いられます。

## 子どものプライバシー

Reminder の年齢区分は 4+ であり、子どもから意図的に個人情報を収集することはありません。

## 変更

本ポリシーを更新した場合は、新しい日付を付けて本ページに掲載します。
