# ペットとアプリ内課金

Reminder には無料の仲間が一体付属しています。追加のイラストペットは任意の、見た目を変えるだけのアプリ内課金です — 購入しなくてもリマインダーの機能はすべて使えます。

## 仲間たち

| ペット | 価格 | 備考 |
|---|---|---|
| British Shorthair | 無料 | 初回起動時に最初からインストール済み |
| Corgi | $3.99 | おすすめ — 陽気なペンブローク・ウェルシュ・コーギー |
| Husky | $3.99 | おすすめ — エネルギッシュなシベリアン・ハスキー |
| Ragdoll Cat | $3.99 | おすすめ — 優雅なラグドール |
| Shiba Inu | $3.99 | おすすめ — 活発で独立心のある柴犬 |
| **All Pets Pack** | **$19.99** | ストアのプレミアムペットをすべて解放 |

表示価格は米ドルの参考価格です。StoreKit が購入時に現地通貨へ換算します。

各ペットには独自のスプライトアニメーション、表情、効果音があります。おすすめのペットにはストア内でバッジが付きます。

## ペットを購入する

1. トレイメニューまたは設定の「ペット」から **ペットストア** を開きます
2. ペットを選んでアニメーションをプレビューします
3. **購入** をクリックし、App Store で確認します
4. パックがダウンロードされ、検証（SHA-256）後にローカルへインストールされます — アカウントは不要です
5. ペットを選択して、アクティブな仲間に設定します

同じ Apple ID でサインインした別の Mac で購入済みのペットは、**購入を復元** をいつでもタップすると解放できます。

## インポートとエクスポート

所有済みの `.catpet` パックをインポートできます。また、インストール済みのペットをエクスポートすれば、仲間を別の環境へ一緒に移せます。インポートしたパックは、インストール前に検証されます。

## ペットの管理

**設定 → ペット** では、アクティブな仲間のプレビュー、ペットの切り替え、動作と外観の調整、リアクション音のオン／オフ、画面ロック中のアニメーション一時停止が行えます。

## よくある質問

- **ペットを購入するとリマインダーの機能が解放されますか？** いいえ。購入は見た目の変更であり、開発の支援になります。
- **購入したペットはオフラインで使えますか？** はい。ダウンロード後、パックは Mac 内に保存されます。
- **パックはどこに保存されますか？** アプリのローカルデータフォルダ内です。[プライバシーに関する選択](./privacy-choices.md) をご覧ください。

購入でお困りの場合は [トラブルシューティング](./troubleshooting.md) をご覧ください。
