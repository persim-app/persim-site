# カスタマイズ

Reminder は可能なところではシステム設定に従い、そうでないところでは邪魔をしません。**設定** は `Cmd+,` またはトレイメニューから開きます。

## 一般

- **表示言語** — 25 の表示言語。変更は開いているすべてのウィンドウに即座に反映されます
- **アクセントカラー** — ボタン、選択範囲、エディターに適用される複数のプリセット
- **ログイン時に起動** — ログイン時に Reminder を起動します
- **トレイアイコンを常に表示** — すべてのウィンドウを閉じていてもメニューバーのアイコンを表示したままにします
- **データフォルダ / ログフォルダ** — ローカルのフォルダを直接開きます
- **オンボーディングをやり直す** — 初回起動時のガイドを再生します

## 外観

ライト／ダークテーマは既定で macOS の設定に従いますが、どちらかに固定することもできます。フローティングのペットウィンドウもアプリ全体に合わせて切り替わります。

## リマインダー

- リマインダーの既定の時刻とスヌーズの長さ
- 通知音、ペットの音、リアクション音
- 「新しいリマインダー」と「ペットの表示／非表示」のグローバルショートカット
- トレイメニューからすべてのリマインダーを一時停止

## ペット

- アクティブな仲間のプレビューと切り替え
- 動作: 待機中の動作、移動、インタラクションへの反応
- 外観: サイズとアニメーション速度
- 画面ロック中はアニメーションを一時停止
- ペットストアを開く、パックをインポートする、購入を復元する

## トレイメニュー

メニューバーのアイコンには、今日の件数、完了件数、次のリマインダーが表示されます。さらに、新しいリマインダー、一時停止／再開、ペットの表示切り替え、設定、終了のクイック操作も用意されています。

ストアについては [ペットとアプリ内課金](./pets.md) を、キーボードショートカットについては [使い方](./usage.md) をご覧ください。
