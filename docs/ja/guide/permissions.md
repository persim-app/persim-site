# アクセス許可

Reminder が求める macOS の許可はごくわずかです。アカウントも、解析も、バックグラウンドのクラウド同期もありません。

## 通知

**必須です。** リマインダーは macOS の標準通知を通じて届けられるため、アプリが前面になくても届きます。初めてリマインダーをスケジュールしたときに macOS が許可を求めます。**システム設定 → 通知 → Reminder** で許可してください。

## ファイルとフォルダ

サンドボックス化された Mac App Store ビルドは、リマインダー、設定、ログ、ダウンロードしたペットパックを専用のコンテナ内に保存します:

```
~/Library/Containers/com.w3cub.reminder/Data/Library/Application Support/com.w3cub.reminder/
```

`.catpet` パックのインポートには macOS の標準ファイル選択ダイアログを使います — アプリが読み取るのは、ご自身で選んだファイルだけです。

## アクセシビリティ / 画面収録

**不要です。** フローティングのペットウィンドウはアプリ自身が描画しており、Reminder が画面をキャプチャしたり、他のアプリの内容を読み取ったりすることはありません。

## ネットワーク

外向きの通信は以下に限られます:

- ペットストアのカタログとペットパックのダウンロード（`app-sources.w3cub.com`）
- 購入と復元のための Apple の StoreKit サービス
- アプリからご自身が送信を選んだ場合の、任意のフィードバック

## 許可の管理

**システム設定 → プライバシーとセキュリティ** を開くと、各項目の確認や取り消しができます。許可を変更したら、Reminder を終了して再起動してください。通知の許可ダイアログを閉じてしまった場合は [トラブルシューティング](./troubleshooting.md) をご覧ください。
