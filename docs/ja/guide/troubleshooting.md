# トラブルシューティング

## リマインダーが届かない

1. **システム設定 → 通知 → Reminder** を開き、通知が許可されているか確認します
2. トレイメニューでリマインダーが一時停止になっていないか確認します
3. スケジュールした時刻に Mac がスリープしていないか確認します
4. Reminder を終了して再起動します

初回起動時の許可ダイアログを閉じてしまった場合、システム設定で再度有効にするまで通知が無効のままになることがあります。

## ペットが表示されない

- トレイメニューでペットが表示設定になっているか確認します（表示／非表示）
- **設定 → ペット** で仲間が選択されているか確認します
- ペットパックのダウンロードが完了しているか確認します。ペットストアを開き直して **購入を復元** をお試しください
- 外部ディスプレイやフルスクリーンアプリを使っている場合は、トレイメニューからペットをメイン画面に戻します

## 購入が反映されない

1. ペットストアを開き、**購入を復元** をタップします
2. 同じ Apple ID で Mac App Store にサインインしているか確認します
3. ネットワーク接続を確認して、再試行します
4. それでも解決しない場合は、製品名を添えて [reminder@w3cub.com](mailto:reminder@w3cub.com) までご連絡ください

## ペットパックのダウンロードに失敗する

アプリは各パックを SHA-256 チェックサムで検証し、失敗したダウンロードを一度だけ再試行します。失敗が続く場合は、ネットワークが不安定であることが多いです。安定した接続で再度お試しください。

## アプリが起動しない

1. Mac を再起動します
2. Mac App Store から再インストールします（ローカルデータはアプリバンドルの外に保持されます）
3. Gatekeeper が GitHub ビルドをブロックする場合は、**システム設定 → プライバシーとセキュリティ → このまま開く** を使います

## ログとデータはどこにありますか？

サンドボックス化されたビルドは、データを次の場所に保存します:

```
~/Library/Containers/com.w3cub.reminder/Data/Library/Application Support/com.w3cub.reminder/
```

**設定 → 一般 → ログフォルダ** から直接開けます。

## 解決しない場合は？

[プロジェクトのリポジトリ](https://github.com/petreminder/reminder) で、macOS のバージョン、Reminder のバージョン、再現手順、ログを添えて Issue を作成するか、[reminder@w3cub.com](mailto:reminder@w3cub.com) までメールでお問い合わせください。
