# プライバシーに関する選択

Reminder はすべてのデータをローカルに保存するため、アクセス・ダウンロード・削除の対象となるサーバー側のプロフィールは存在しません。お使いの Mac 上で、ご自身が直接管理できます。

## データはローカルに留まります

- リマインダー、リスト、ノート、タグ、サブタスク
- 統計、連続記録、実績
- 設定、ショートカット、ダウンロードしたペットパック

当方は個人情報を収集、販売、共有することはなく、第三者の解析サービスや広告サービスも利用しません。

## データの管理と削除

- アプリ内で個別のリマインダー、リスト、ノートを削除できます
- コピーを残したい場合は、削除前にアプリからデータをエクスポートできます
- Reminder を終了してコンテナを削除すると、すべてを削除できます:

```bash
rm -rf ~/Library/Containers/com.w3cub.reminder
```

開発ビルドではコンテナ外にデータを保存する場合があります。正確なパスは **設定 → 一般 → データフォルダ** でご確認ください。

## 任意のネットワーク機能

- ペットストアのカタログとペットのダウンロードは、ストアを開いたとき、またはペットを購入したときにのみ利用されます
- フィードバックは、アプリ内フォームを明示的に送信したときにのみ送信されます
- Reminder にはクラウド同期もアカウントも存在しないため、オプトアウトの対象となるものはありません

## アプリ内課金

購入と復元は Apple が処理します。購入履歴の確認や管理には、Apple ID で Mac App Store をご利用ください。新しい Mac でペットを解放するには、ペットストアの **購入を復元** をお使いください。
