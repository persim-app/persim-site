# ガイド

Reminder ユーザーガイドへようこそ。Reminder 2.0.0 は、macOS のための静かでローカルファーストなリマインダーアプリです。Rust + GPUI で一から作り直され、連続記録とともに育つ小さな仲間も付いています。
